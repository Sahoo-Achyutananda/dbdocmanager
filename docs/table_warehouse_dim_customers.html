Customer dimension table with denormalized contact information

Columns

Name Type Constraints Description
customer_id INTEGER PK AUTO Surrogate key for customer dimension
email VARCHAR(255) UNIQUE NOT NULL Primary email address (normalized to lowercase)
full_name VARCHAR(200) NOT NULL Customer full name (first + last)
address_street VARCHAR(500) Street address
address_city VARCHAR(100) City
postal_code VARCHAR(20) ZIP/Postal code
created_at TIMESTAMP NOT NULL DEFAULT: CURRENT_TIMESTAMP Record creation timestamp
